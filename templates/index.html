Sanitization App

Overview

The Sanitization App removes sensitive text from your files using regex rules you manage from the browser — no coding required. It scans file contents and filenames, replaces every matched character with X, and lets you download the cleaned result. Nested archives (zip, rar, 7z, etc.) are extracted, sanitized, and repackaged automatically.

How It Works

  1. Set your rules — Open the Rules tab and add patterns (one per line), or upload a .txt rules file.
  2. Upload files — Go to Upload, select your file(s), and click Upload.
  3. Wait for processing — Keep the browser open. A Job ID is shown for each file.
  4. Download results — When done, click the download link. Stats show how many replacements were made.
Tip: If a file has no matches, no download is generated. Add or adjust rules in the Rules tab and upload again.

What Gets Sanitized

  • File contents — Text inside .txt, .log, .csv, Excel (.xlsx, .xls), and text files inside archives
  • Filenames — Invalid or non-ASCII characters in file and folder names
  • Nested archives — Archives inside archives are opened and processed recursively
  • Non-ASCII characters — Automatically replaced with X even without a rule

Beginner tip: Start with simple plain-text patterns like csv, 2023, or a person's name. They match anywhere in the file. Use \bword\b only when you need to match a whole word and not part of another word.
Special characters: Characters like . * + ? [ ( have special meaning in regex. To match them literally, add a backslash: \. matches a dot, \* matches an asterisk.

Upload Tab — Tips

  • Do not close or refresh the browser while a file is processing
  • Note the Job ID shown after upload — it can be used to check status later
  • Large files (over 50 MB) are processed line-by-line to save memory
  • If upload fails with "file too large", the limit is {{ max_label }} per file
  • Archive processing requires 7-Zip — installed automatically on first start (Ubuntu: via apt; macOS: via Homebrew)

Frequently Asked Questions

Why was no download link shown?

No rule matched anything in the file. Add or adjust rules and upload again.

Why does andy become XXXX and not XXX?

Each matched character is replaced with one X. The word "andy" has 4 characters, so it becomes 4 Xs.

Can I use plain words without regex knowledge?

Yes. Typing a plain word like csv or 2023 works as a pattern and matches that text anywhere in the file.

Do rules apply to all future uploads?

Yes. Rules are saved permanently on the server until you change or clear them.

What happens to comments in the rules file?

Lines starting with # are comments and are ignored. They are useful for notes and documentation.

I refreshed the page — did I lose my tab?

The app remembers your last tab in the URL (e.g. #rules). Bookmark or note the Job ID if processing was in progress.
